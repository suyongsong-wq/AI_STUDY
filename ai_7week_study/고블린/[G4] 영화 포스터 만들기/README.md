## 2. 레퍼런스 분석

`레퍼런스/ref_nowayhome.jpg` (Spider-Man: No Way Home 공식 포스터)를 놓고 원사이트 문법을 해부했다.

| 층위 | 역할 |
|---|---|
| 상단 | 태그라인 (넓은 자간, 얇게) |
| 중앙 | 키비주얼 — 캐릭터가 화면의 주인 |
| 하단 타이틀존 | 타이틀 트리트먼트(레드→블루 그라데이션) → 스크립트 부제 → 개봉 정보 → 빌링 블록 |
| 공통 | 하단으로 갈수록 짙어지는 그라데이션으로 **글자 자리를 만든다** |

**핵심**: 포스터는 "예쁜 이미지 + 글자"가 아니라 **정보 위계가 고정된 조판 양식**이다. 태그라인 → 비주얼 → 타이틀 → 부제 → 날짜 → 빌링. 이 순서가 곧 시선 순서다.

## 3. 제작 방식

- **키비주얼·스틸컷 생성**: [Pollinations.ai](https://image.pollinations.ai) `flux` 모델 (API 키 불필요·무료)
  - 대안 검토: `gemini-2.5-flash-image` → **429**(무료 티어 이미지 쿼터 0) / OpenAI GPT Image → **키 없음**
  - 무료 티어 출력 상한은 **약 59만 픽셀** — 1920×1080 요청 시 1024×576, 1024×1536 요청 시 627×940로 강등됨. 그래서 **합성 캔버스를 목표 규격으로 잡고** 생성물을 레이어로 사용
- **조판**: HTML/CSS → Chrome DevTools 1350×2000 캡처
- **폰트**: Anton(타이틀) · Oswald(태그라인·빌링) · Cormorant Garamond Italic(부제) · Pretendard(한글)
- **타이틀 트리트먼트**: `background-clip:text`로 레드→블루 그라데이션 + SVG 텍스트 마스크로 **글자 안쪽에만** 웹 패턴 오버레이

> 🔧 **막힌 지점**: Playwright 스크린샷이 1350×2000에서 계속 5초 타임아웃 → 원인은 `box-shadow: inset 0 0 320px 90px` 비네트. 이 크기 캔버스에서 블러 렌더가 감당이 안 됐다. `radial-gradient` 비네트로 교체하니 즉시 해결.

## 5. 실패와 수정 기록

**스틸 03·04·05를 폐기하고 재생성했다.** (`스틸컷/_폐기_오프모델/`에 원본 보존)

| 컷 | v1 문제 | 원인 | 수정 |
|---|---|---|---|
| 03 | 검은 수트의 자경단으로 나옴 — 스파이더맨이 아님 | 프롬프트에 `masked hero`라고만 씀 | `bright RED AND BLUE spider suit with web pattern` + `red suit clearly visible` 명시 |
| 04 | 렌즈가 **동그란 물안경**처럼 나오고 색이 탁함 | `red spider hero mask`만 쓰고 렌즈 형태를 지정 안 함 | `large ANGULAR WHITE reflective lenses with black rims` + `fine black web lines` 명시 |
| 05 | 트렌치코트 입은 형사처럼 나옴 | `hero silhouette`이라고만 써서 모델이 느와르 탐정으로 해석 | 수트 색 명시 + `standing small in the foreground` 로 구도 지정 |

### 04는 3안을 뽑아 비교했다 (`스틸컷/_후보_04/`)

| 안 | 내용 | 판정 |
|---|---|---|
| 04a 정면·각진렌즈 | 문제를 정면으로 수정. 각진 흰 렌즈 + 선명한 레드 | 가장 확실하게 읽히나 **밝고 쨍해서 시퀀스에서 튐** |
| **04b 측면·네온반사** ✅ | 프로필 앵글, 렌즈에 핑크/시안 네온 | **채택** — 포스터 A·스틸 01·02의 비·네온 느와르 톤과 붙음. "예고편 마지막 컷" 역할에 여백이 맞음 |
| 04c 유리창 반사 | 비 젖은 유리에 비친 실루엣 | 탈락 — **눈이 검은 구멍**(흰 렌즈 없음)이라 오프모델 |

> **배운 것 1**: 생성형 이미지에서 "히어로"는 지시가 아니다. **색·소재·패턴처럼 검증 가능한 명사**로 써야 모델이 따라온다. 스타일 형용사(cinematic, moody)는 잘 먹지만 **정체성은 형용사로 안 잡힌다.**
> **배운 것 2**: 컷 하나를 고를 때 기준은 "이 컷이 예쁜가"가 아니라 **"옆 컷들과 톤이 붙는가"**다. 04a가 단독으로는 더 잘 만들어졌지만, 나머지 5컷이 느와르라 04b가 맞았다.
