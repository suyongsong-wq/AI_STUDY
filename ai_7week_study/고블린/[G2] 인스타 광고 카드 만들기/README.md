## 2. 브랜드 톤앤매너 — 실측 데이터

퀘스트 팁이 *"브랜드 피드를 먼저 훑으면서 공통된 톤앤매너를 파악하고 시작하세요"* 라고 해서, **크롬 MCP로 `toss.im`에 접속해 실제 렌더된 값을 추출**했다. (2026-07-14 기준)

| 항목 | 실측값 | 근거 |
|---|---|---|
| 브랜드 컬러 | **#3182F6** (`rgb(49,130,246)`) | 사이트 전체에서 36회 등장 — 최다 브랜드 컬러 |
| 폰트 | **Toss Product Sans** + Tossface | `body`의 `font-family` 최우선 값 |
| 텍스트 | `#212529` / `#6B7684` | Grey900 / Grey600 |
| 배경 | `#FFFFFF` / `#F9FAFB` | 화이트 + 미세 그레이 |
| 실제 카피 | "금융의 모든 것 토스에서 쉽고 간편하게"<br>"세금 납부, 등본 발급까지 **토스로 한 번에**" | `h1`/`h2` 실측 |

**폰트 대체**: `Toss Product Sans`는 비공개 자체 폰트라 로컬에 없다. 자소 폭·기하학적 골격이 가장 가까운 **Pretendard**로 대체했다. (임의 선택이 아니라 대체 사유를 남긴다)

## 3. 카피의 근거 — 지어내지 않았다

광고 카피는 **토스가 실제로 쓰는 문구**에서만 가져왔다.

| 내가 쓴 카피 | 근거가 된 토스 실제 문구 |
|---|---|
| "등본 발급도 토스로 한 번에." | "세금 납부, **등본 발급까지 토스로 한 번에**" (h2) |
| "금융의 모든 것, 쉽고 간편하게." | "**금융의 모든 것 토스에서 쉽고 간편하게**" (h1) |
| 기능 3종 (등본·초본 / 세금 납부 / 부동산·자동차) | "세금 납부, 등본 발급까지" · "**내 부동산 · 자동차** 정기적으로 관리해보세요" (h2/h3) |

> ⚠️ **없는 혜택·수치(금리·할인율·기간 한정 등)는 한 줄도 넣지 않았다.** 6주차 Q4에서 인플루언서 참여율을 지어냈다가 감점된 것과 같은 실수를 피하기 위함. 실존 브랜드 광고에서 가짜 혜택을 만들면 그건 습작이 아니라 허위광고다.

## 4. ⚖️ IP 관련 — 이 결과물의 성격

토스는 비바리퍼블리카의 실존 브랜드다. 이 과제물은 **디자인 연습용 습작(모작)**이며 다음을 지켰다.

- **토스 공식 로고 파일을 쓰지 않음** — 워드마크는 텍스트로 조판
- **없는 혜택·수치를 만들지 않음** (§3)
- 모든 카드 하단에 `학습용 디자인 습작 · 토스와 무관합니다` **명시**
- 비상업 · 교육 목적 · 실제 게재 안 함

## 6. 제작 방식

- **3D 아이콘**: Pollinations.ai `flux` (무료·키 불필요) — clay render 스타일
  - `gemini-2.5-flash-image`는 무료 티어 쿼터 0(429), OpenAI 키 없음
- **조판**: HTML/CSS → Chrome DevTools 1080×1080 캡처
- **폰트**: Pretendard (Toss Product Sans 대체) · 이모지는 시스템 이모지

> 🔧 **수정 기록**: 처음엔 아이콘 패널에 자체 그라데이션 배경을 깔고 `mix-blend-mode:multiply`로 합성했더니, 생성 이미지의 파란 배경과 충돌해 **붙여넣은 티가 났다.** 생성 아이콘이 이미 자체 배경을 갖고 있으므로 패널 배경을 걷어내고 이미지를 그대로 채우니 해결. **억지로 합성하지 말고 소재가 이미 가진 것을 살릴 것.**
