## 2. 나를 한 단어로 정의하면

> **"만들면서 배우는 실용주의 빌더"**

퀘스트가 요구한 *"처음 만난 사람이 5초 만에 이 사람 뭐 하는 사람이지?"* 에 답하는 축.
직함(회사 타이틀)이 아니라 **일하는 방식**을 정체성으로 잡았다 — `about-me.md` 전체를 관통하는 게 "이론보다 작동하는 결과물"이기 때문.

## 3. 디자인 판단

### 컬러·폰트 — 본인 취향에서 도출
`about-me.md` §7: *"토스(Toss) 스타일과 **글래스모피즘** 같은 감각적인 디자인에 끌린다"*

- **메인** `#3182F6` (Toss Blue — G2에서 `toss.im` 실측한 값 재사용)
- **보조** `#191F28` (Grey900) · `#8B95A1` (Grey500)
- 헤더에 **글래스모피즘** 배지 (`backdrop-filter: blur(14px)`) — 취향 반영
- 폰트 **2종**: Pretendard(본문) + JetBrains Mono(이메일·핸들·번호)
  → 모노 폰트를 연락처에만 쓴 이유: 이메일·URL은 **한 글자도 틀리면 안 되는 정보**라 자간이 고른 서체가 오독을 막는다

### 핵심 정보 5가지 — 팁의 "5가지 이내" 준수
1. 이름 + 한 줄 정체성
2. 지금 만드는 것 (Trailmark)
3. 만든 것 (20+)
4. 일하는 방식 (칩 4개)
5. 연락 (이메일 + GitHub + QR)

### 강조는 1개만
팁: *"보여주고 싶은 핵심 정보 1개는 크기·색으로 강조"*
→ **"작동하는 걸 손으로 만들면서"** 한 구절에만 블루 + 하이라이트 배경. 나머지는 전부 무채색.

## 4. 결과물 — 앞면 + 뒷면 (보너스 +5pt)

| | 앞면 | 뒷면 |
|---|---|---|
| 파일 | `프로필카드_앞면_1080x1350.png` | `프로필카드_뒷면_1080x1350.png` |
| 역할 | **소개** — 누구이고 어떻게 일하는가 | **포트폴리오** — 실제로 뭘 만들었는가 |
| 톤 | 화이트 + 블루 헤더 | Grey900 다크 반전 |
| 구성 | 이름·태그라인·정보 4행·QR | 프로젝트 6종 리스트 + 스탯 3개 |

> 앞/뒤 톤을 **화이트 ↔ 다크로 반전**시킨 이유: 명함을 뒤집었을 때 "다른 면"이라는 게 즉시 인지된다. 같은 톤이면 뒤집은 걸 눈치채지 못한다.

## 5. 규격·검증

| 체크 | 결과 |
|---|---|
| 1080×1350 (인스타 4:5) | ✅ 앞/뒤 `sips` 실측 |
| 핵심 정보 5가지 이내 | ✅ 5개 |
| 컬러 메인 1~2 + 보조 1 | ✅ 블루 1 + 그레이 2 |
| 폰트 2개 이내 | ✅ Pretendard + JetBrains Mono |
| QR / 링크 연결 | ✅ `github.com/suyongsong-wq` |
| **흑백 출력 판독** | ✅ `검증_흑백/` — 전 항목 판독 가능, QR 스캔 유지 |

> 🔧 **수정 기록**: 초안은 본문이 위로 몰리고 하단에 큰 구멍이 생겼다. `.body`를 `justify-content:center`로 바꿔 남는 공간을 위아래로 나누니 균형이 잡혔다. **여백은 많아서 고급스러운 게 아니라 고르게 나뉘어야 고급스럽다.**
> 뒷면 스탯의 `7 주차 완주`는 **사실과 달라 수정**했다 — 7주차는 지금 진행 중이라 `7 주차 진행 중`으로 바꿨다.
