# 📜 일반 퀘스트

## 1. [Server+DB] 가계부 앱
> 🎯 **Server + DB(Supabase)**를 조합해 나만의 가계부 앱 만들기

**미션**
1. 수입/지출 내역 등록 (날짜·금액·카테고리·메모)
2. 등록된 내역 목록 조회
3. 카테고리별 합계 표시 (식비·교통·주거·구독료·경조사 등)
4. 모든 데이터는 Supabase DB에 저장

**핵심 구조**: `입력 → Server → DB 저장 → 내역 조회 & 카테고리별 합계 → 응답`

**제출물**: GitHub 링크 · 동작 스크린샷(1장+) · 에이전트 대화 스크린샷(1장+)

**팁**
- 테이블 컬럼: `type`(수입/지출), `category`, `amount`, `memo`, `date`
- 카테고리별 합계는 SQL `GROUP BY` 활용
- 여유 되면 월별 차트·예산 대비 사용량 도전

## 2. [Agent+DB] 내 가계부 DB를 분석하는 에이전트
> 🎯 1번 가계부의 Supabase DB에 에이전트를 연결 → **말로 물어보는 소비 분석가**

**⚠️ 전제**: 1번 가계부 앱 완료 + 지출 데이터 10건 이상 적재

**미션**
- **Part 1**: 에이전트가 가계부 Supabase DB에 접속하도록 연결
- **Part 2**: 자연어로 질문
  - 기본 조회: "이번 달 얼마 썼어?", "식비 가장 많이 쓴 날?"
  - 패턴 분석: "주중 vs 주말 비교", "카테고리별 비율"
  - 절약 조언: "줄일 수 있는 것 추천", "남은 예산 얼마?"

**핵심**: 앱은 데이터를 *쌓는* 도구, 에이전트는 *활용*하는 도구 — DB는 둘의 공유 자산

**제출물**: GitHub 링크 · 에이전트 대화 스크린샷(조회/분석/조언 각 1장) · 가계부 앱 데이터 화면

**팁**: 같은 Supabase 프로젝트·테이블에 연결 · Supabase MCP 활용 · 질문은 구체적으로

**⚠️ 전제**: 튜토리얼 *Sign In & Sign Up & Profile*, *Todo App (+ Login & DB)* 완료 · Supabase 준비

**미션**
- **Part 1**: 회원가입 & 로그인 화면
- **Part 2**: 게시글 CRUD — 작성(로그인 필수) / 조회(누구나·작성자 표시) / 수정·삭제(본인만)
- **Part 3**: 게시글 목록 (최신순, 제목·작성자·시간, 클릭 시 상세)

**제출물**: 배포 URL · GitHub 링크 · 스크린샷(가입→로그인→글쓰기→목록) · (보너스) 본인 외 1명 가입·작성

**팁**: Todo App 구조 재활용(Todo→게시글) · RLS로 "본인 글만" 처리 · 일찍 배포해 공유

## 4. [Auth + DB] 쇼핑몰 (결제 기능 제외)
> 🎯 상품 목록 → 장바구니 담기 → 장바구니 관리 (결제 없음)

**⚠️ 전제**: 튜토리얼 *Sign In & Sign Up & Profile*, *Todo App (+ Login & DB)* 완료 · Supabase 준비

**미션**
- **Part 1**: 상품 목록 (상품명·가격·이미지·설명, 로그인 없이도 조회)
- **Part 2**: 회원가입 & 로그인 (장바구니 사용 시 필요)
- **Part 3**: 장바구니 — 담기 / 조회 / 수량 변경(+/-) / 삭제 / 합계 자동 계산
- **Part 4**: Vercel 배포

**DB 구조 참고**
```
products: id, name, price, image_url, description   (공개)
cart:     id, user_id, product_id, quantity         (본인만)
```

**주제 예시**: 의류 · 문구/굿즈 · 디저트/베이커리 · 식물 가게 · 중고 전자기기

**제출물**: 배포 URL · GitHub 링크 · 스크린샷(목록→담기→관리→합계)

**팁**: 샘플 상품은 "10개 만들어서 DB에 넣어줘"로 · 이미지는 Unsplash · "주문하기"는 "준비 중" 알림으로 OK

## 5. [My Agent] 관심 분야 자동 리서치 스킬 만들기
> 🎯 반복하는 **웹 리서치 → md 정리 → 노션 공유**를 재사용 가능한 **스킬(SKILL.md)**로 박제
> 💡 핵심: 에이전트는 **한 번**, 스킬은 **매번**

**⚠️ 전제**: 브라우저 MCP(크롬/Playwright) 연결 (Notion MCP 연결 시 보너스)

**미션**
- **Part 1**: 매주 돌릴 리서치 주제 1개 정하기 (채용공고·맛집·부동산·뉴스·중고거래·경쟁카페 등)
- **Part 2**: 손으로 한 번 시켜서 워크플로 확정 (사이트 3곳+ 탐색 → `research.md` → 노션)
- **Part 3 (핵심)**: 그 절차를 `.claude/skills/research/SKILL.md`로 박제
  - `description`에 **언제 쓰는지** 명시
  - 본문 절차: ① 주제·키워드 묻기 → ② 브라우저 MCP로 3곳+ 탐색 → ③ 정해진 포맷 md → ④ 노션 공유
  - md 포맷: 제목 / 수집일 / 출처별 핵심 / 한 줄 요약 / 다음 액션
- **Part 4**: 새 대화에서 "관심분야 리서치 해줘" 한마디로 재호출 검증 (키워드 바꿔 2회)

**제출물**: 주제·사이트 목록 · 자동 탐색 스크린샷(3장+) · `SKILL.md` · 재호출 결과 2개 · (보너스) 노션 업로드

**팁**: "매주 돌릴" 주제일수록 가치 큼 · *손으로 한 번 → 박제 → 고쳐쓰기* 순서

# 🅿️ 카페 사장님 시나리오 퀘스트

> 🏪 '하버 카페' 사장님 지우 씨처럼, 내 카페를 AI로 굴려보는 연속 퀘스트.
> **6번에서 만든 `my_cafe.md`가 7~10번 전부의 '내 데이터' 기반**이 됩니다. (카페 버전의 MISSION.md)

## 6. 내 카페 컨셉 정하기 — AI와 대화해서 `my_cafe.md` 만들기
> 🎯 카페 창업 여정의 **출발점**. AI를 창업 컨설턴트로 삼아 컨셉을 구체화하고 파일로 박제

**실습**
1. 클로드 코드에 "카페 창업 컨설턴트" 역할 부여 → **한 번에 하나씩** 질문받기
   순서: ① 타겟 손님 → ② 위치·상권 → ③ 시그니처 메뉴 → ④ 분위기·인테리어 → ⑤ 가격대 → ⑥ 차별점 → ⑦ 이름·슬로건
2. 솔직하게 답하기 (한 단어만 던져도 AI가 살을 붙임)
3. 완성된 `my_cafe.md` 확인

**산출물 포맷**: 카페 이름 / 한 줄 컨셉 / 타겟 손님 / 위치·상권 / 시그니처 메뉴 / 분위기·인테리어 / 가격대 / 차별점 / 슬로건

> 💡 이후 모든 카페 퀘스트에서 "하버 카페" 대신 이 파일을 근거로 시키면 전부 '내 카페' 맞춤이 됨

## 7. [Context+Agent+DB] 내 카페를 아는 AI 에이전트
> 🎯 `my_cafe.md`(컨셉) + DB(운영 데이터)를 결합한 **맞춤형 AI 운영 파트너**. Context 없이 vs 있이 비교

**⚠️ 전제**: 튜토리얼 *내 AI Context 만들기*, *대시보드(.md)+세부데이터 구조* + 6번(`my_cafe.md`) 완료

**미션**
- **Part 1**: `my_cafe.md` 준비 (6번 결과물)
- **Part 2**: DB에 카페 운영 데이터 적재 (일별 매출·메뉴별 판매량·리뷰·재고·요일별 손님 수 등)
- **Part 3**: 에이전트가 `my_cafe.md` + DB 둘 다 읽고 내 카페 맞춤 답변
- **Part 4**: **Before/After 비교 시연** (컨텍스트 없이 vs 있이)

**시나리오 예시**: "신메뉴 뭐 추가할까?"
- Context 없는 AI: "딸기라떼, 크로플 추천" (일반적)
- 내 에이전트: "말차라떼가 매출 1위니 말차 티라미수로 확장, 오래 머무는 손님 많으니 콜드브루 추가" (맞춤형)

**제출물**: GitHub 링크(`my_cafe.md`+코드) · Before/After 스크린샷(2쌍+) · `my_cafe.md` 화면

**팁**: `my_cafe.md`에 제약사항(예산·좌석 수·주방 인력·재료)을 넣으면 답변이 실용적으로 바뀜

## 8. 손님 리뷰·경쟁사 분석 → 엑셀/PPT 보고서 (20점)
> 🎯 리서치 산출물을 **회의에 바로 들고 갈 엑셀/PPT 보고서**로 변환
> 🔧 준비: `document-skills` 스킬

**미션**: 5주차 실무 에이전트 산출물 하나를 엑셀(.xlsx) 또는 PPT(.pptx) 보고서로 완성

**두 경로 (샘플 데이터 제공)**
- **경로 A — VoC 엑셀**: `cafe_reviews.csv`(리뷰 데이터) → 별점 분포 막대 차트 + 테마별 피벗 + 부정 리뷰(별점 2↓) Top3
  → 기대: 긍정은 맛·디저트, **부정 1위는 '대기시간'**
- **경로 B — 경쟁사 PPT**: `competitors.md` → 표지 / 시장 개요 / 비교표 / 차별화 / 추천 액션
  → 기대: 추천에 '인플루언서 협업'이 들어가 9번 홍보 편과 연결

**필수 제출물**
1. 원천 데이터/리서치 결과 (`.md` 또는 `.csv`)
2. 변환된 `.xlsx`(수식·차트·서식) 또는 `.pptx`(표지·분석·추천·다음액션)
3. 생성 과정 + **결과 파일 열어본 실행 스크린샷**
4. (가점) 노션/메일 공유

**루브릭(20)**: 기능 10(데이터 기반·박제X) / 실행 스샷 4 / 완성도 4 / 창의 2

> 💡 두 경로 모두 해보면 리서치가 의사결정 보고서로 바뀌는 흐름을 끝까지 경험. `my_cafe.md` 기준이면 만점에 더 가까움

## 9. [홍보] 우리 카페 띄워줄 인스타 인플루언서 찾기 (20점)
> 🎯 우리 카페와 결이 맞는 인스타 인플루언서를 **Playwright MCP**로 직접 발굴 → Top 5 + 컨택 메시지
> 💡 팔로워 수보다 **인게이지먼트율(좋아요+댓글÷팔로워)**과 **타겟과의 결**이 핵심

**미션**: 본인 인스타 로그인 세션에서 후보 발굴 → 실제 게시물 데이터로 인게이지먼트율·적합도 계산 → Top 5 + 컨택 메시지

**진행**
1. Playwright로 instagram.com 열고 직접 로그인 → `#동네카페 #분위기좋은카페 #카페추천 #디저트맛집` 및 경쟁 카페 태그 게시물에서 결 맞는 후보 수집
   - 후보별: 팔로워 / 최근 9개 평균 좋아요·댓글 / 인게이지먼트율 / 타겟 적합도(한 줄)
2. 인게이지먼트율+적합도로 정렬 → `influencers.md`에 Top 5 표 + 상위 3명 DM 컨택 초안(무료 음료 체험 + 게시물 1건)

**필수 제출물**: 타겟 정의(2~3줄, `my_cafe.md` 근거) · Playwright 탐색 스크린샷 · 후보 표(5명+) · Top 3 추천+컨택 초안 · (가점) .xlsx/.pptx 또는 노션 공유

**루브릭(20)**: 발굴 6 / 분석 6(실데이터 인게이지먼트율) / 추천·적합도 4 / 컨택 2 / 창의 2

> ⚠️ **안전 수칙**: 본인 계정으로 사람처럼 천천히. 대량 스크래핑·DM 자동 발송 금지(계정 정지 위험). 자동화는 후보 발굴·열람까지만, 실제 컨택은 사람이 직접

## 10. [Auth+MCP+DB+App] 내 카페 사장님 대시보드 앱 (보스 퀘스트)
> 🎯 **Auth + MCP + DB + AI**를 하나의 앱에 종합. 로그인하면 카페 데이터가 한 화면에 모이고 AI가 브리핑
> ⚠️ **도전 퀘스트** — 다른 5주차 퀘스트를 먼저 완수한 뒤 추천. 위젯 2~3개만 동작해도 인정!

**미션**
- **Part 1**: 로그인/회원가입 (사장님만 접근)
- **Part 2**: 데이터 소스 2개 이상 연결 — Notion MCP(할일/발주) / Supabase DB(매출·판매·재고) / 외부 API(날씨·뉴스)
- **Part 3**: AI가 데이터를 종합한 **"오늘의 카페 브리핑"** 생성
- **Part 4**: 대시보드 UI에 표시 + Vercel 배포

**대시보드 예시**: 오늘 할일(Notion) · AI 브리핑 · 이번 주 매출(DB) · 인기 메뉴 TOP3(DB)

**제출물**: 배포 URL · GitHub 링크 · 스크린샷(로그인→데이터 표시→AI 브리핑) · 연결한 데이터 소스 목록

**팁**: 완벽 추구 금지 — 매출 위젯 하나부터 점진적 추가 · 4주차 코드 재활용 · AI 브리핑은 "어제 매출+인기 메뉴 요약"부터
> 7주차 파이널 프로젝트의 프로토타입으로 발전 가능
