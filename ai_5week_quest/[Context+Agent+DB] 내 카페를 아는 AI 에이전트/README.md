# 🅿️ [Context+Agent+DB] 내 카페를 아는 AI 에이전트

> 🎯 `my_cafe.md`(컨셉) + DB(운영 데이터)를 결합한 **맞춤형 AI 운영 파트너**. Context 없이 vs 있이 비교하면 차이가 확실.
> 구분: 🚩퀘스트 · 제출 기한: 토요일 23:59 PM

## ⚠️ 전제 조건
수업 튜토리얼 **내 AI Context 만들기**, **대시보드(.md) + 세부데이터 구조**, 그리고 프로젝트 **내 카페 컨셉 정하기(my_cafe.md)** 완료. (Supabase에 카페 운영 데이터가 있으면 더 좋음)

## 미션
### Part 1: AI Context 파일(`my_cafe.md`) 준비
카페 컨셉 퀘스트에서 만든 `my_cafe.md`를 그대로 가져오기. (없으면 먼저 만들기)

### Part 2: DB에 카페 운영 데이터 넣기
자유 주제로 — 일별 매출, 메뉴별 판매량, 손님 리뷰, 재고/발주, 요일별 손님 수 등.

### Part 3: Context + DB 결합 에이전트 구성
에이전트가 `my_cafe.md`(컨셉)와 DB(운영 데이터)를 모두 읽어 내 카페에 맞는 답변.

### Part 4: Before / After 비교 시연
**"카페 컨텍스트 없이 질문" vs "my_cafe.md 있이 질문"** 비교.

**시나리오 예시 — "신메뉴 뭐 추가할까?"**
- Context(my_cafe.md): 타겟 20~30대 여성, 시그니처 말차라떼·치즈케이크, 오래 머무는 작업 카페
- DB: 최근 2주 메뉴별 판매·매출
- Context 없는 AI: "딸기라떼, 크로플 추천" (일반적)
- 내 에이전트: "말차라떼가 매출 1위니 '말차 티라미수'로 확장, 오래 머무는 손님 많으니 콜드브루 추가" (맞춤형)

**다른 주제 예시**: 마케터(요일별 손님 수→프로모션) · 메뉴 기획자(판매량→신메뉴/단종) · 리뷰 분석가(리뷰→개선 우선순위) · 재고 관리자(사용량→발주 타이밍)

## 핵심 구조
```
[AI Context (my_cafe.md)] + [카페 운영 DB] → [에이전트가 둘 다 읽음] → [내 카페에 맞는 맞춤 답변]
```
