# 🅿️ [홍보] 우리 카페 띄워줄 인스타 인플루언서 찾기 (20점)

> 🏪 **시나리오** — 하버 카페는 커피·디저트는 자신 있는데 **아무도 모른다**(팔로워 2,400 vs 경쟁사 12,500). 광고비는 빠듯. 그래서 **결이 맞는 인스타 인플루언서**를 직접 찾아 협업을 제안한다.
> 🔧 도구: Claude Code + **Playwright MCP**(진짜 인스타 브라우저)
> 🧩 5주차 '카페 창업' — 홍보 편 · 구분: 🚩퀘스트

## 왜 사장님 일인가
- 딱 맞는 동네/감성 인플루언서 1명은 단골을 데려온다.
- 문제는 '누구에게 연락하지?' — 팔로워만 많은 사람은 비싸고 효과도 애매.
- 핵심은 **인게이지먼트율(좋아요+댓글 ÷ 팔로워)**과 **우리 타겟과의 결**. 이걸 AI가 인스타를 돌며 계산.

## 미션
Playwright로 **본인 인스타 로그인 세션**에서 후보를 발굴하고, 실제 게시물 데이터로 **인게이지먼트율·적합도**를 따져 **Top 5 추천 + 컨택 메시지**를 만든다.

## 진행 (그대로 복붙해서 시작)
> **Playwright로 인스타그램(instagram.com)**을 열어줘. 내가 직접 로그인할게. 그다음 `#동네카페 #분위기좋은카페 #카페추천 #디저트맛집` 같은 해시태그와 경쟁 카페 계정의 태그된 게시물에서 **우리 카페(아늑한 동네 카페, 말차라떼·수제 디저트, 20~30대 여성 타겟)와 결이 맞는 인스타 계정 후보**를 모아줘. 각 후보마다 **팔로워 수 / 최근 게시물 9개의 평균 좋아요·댓글 / 인게이지먼트율 / 우리 타겟 적합도(한 줄 이유)**를 정리해줘.

그다음:
> 후보들을 **인게이지먼트율 + 적합도** 기준으로 정렬해서 `influencers.md`에 **Top 5 표**로 만들고, 상위 3명에게 보낼 **DM 컨택 메시지 초안**(협업 제안 — 무료 음료 체험 + 게시물 1건)도 각각 적어줘.

## 필수 제출물
1. **타겟 정의** — 우리 카페가 노리는 손님 (지역/연령/감성, 2~3줄). `my_cafe.md`가 있으면 그걸 근거로.
2. Playwright로 **인스타 탐색하는 실행 스크린샷** (해시태그·후보 프로필 화면)
3. **후보 리스트 표 (최소 5명)** — 계정 / 팔로워 / 인게이지먼트율 / 적합도
4. **Top 3 추천 + 컨택 메시지 초안**
5. (가점) `document-skills`로 .xlsx/.pptx 정리하거나 노션 공유

## 루브릭 (20점)
| 항목 | 배점 | 기준 |
|---|---|---|
| 발굴 | 6 | Playwright 탐색 + 후보 5명+ (스샷 증빙) |
| 분석 | 6 | 팔로워가 아니라 **인게이지먼트율(실데이터)**로 비교 |
| 추천·적합도 | 4 | Top 3 추천 이유가 우리 타겟과 연결 |
| 컨택 메시지 | 2 | 바로 보낼 수 있는 자연스러운 제안 |
| 창의 | 2 | 문서화·노션 공유·자동화 등 |

> 💡 `my_cafe.md` 기준으로 돌리면 그대로 내 카페 맞춤 후보가 나온다.
> ⚠️ **안전 수칙**: 반드시 본인 계정 로그인 세션에서 **사람처럼 천천히**. 대량 자동 스크래핑·DM 자동 발송 **금지**(계정 정지 위험). 자동화는 **후보 발굴·열람까지만**, 실제 컨택은 사람이 직접.
