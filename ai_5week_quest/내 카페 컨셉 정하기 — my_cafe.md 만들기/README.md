# 🅿️ 내 카페 컨셉 정하기 — AI와 대화해서 `my_cafe.md` 만들기

> 🏪 5주차 '카페 창업' 여정의 **출발점**. AI를 창업 컨설턴트로 삼아 내 카페 컨셉을 구체화하고 `my_cafe.md`로 박제.
> 이 파일이 이후 **홍보·조사·운영** 퀘스트 전부의 '내 데이터'가 됨. (카페 버전의 MISSION.md)
> 구분: 🚩퀘스트

## 📖 하버 카페 이야기 (시나리오)
마케터였던 **지우** 씨는 회사를 나와 골목 끝 10평짜리 카페 *하버 카페*("잠시 쉬어가는 항구")를 열었다. 메뉴는 말차라떼와 수제 치즈케이크. 그런데:
- 오픈 첫 주 하루 손님 11명 — 아무도 하버 카페를 모른다.
- 옆 골목 *스윗아워*는 인스타 팔로워 1.2만, 주말이면 줄 선다.
- 임대료·알바비·재료비는 매달 꼬박 나간다.

지우 씨에겐 'AI 공장장'이 있다. 막막한 일을 하나씩 AI에 시킨다 → 사입 견적, 인플루언서 찾기, 리뷰·경쟁사 조사, 손익 보고서. **5주차는 이 도구들을 직접 만든다.**

## 🎯 실습 — 당신의 카페를 AI와 정하기
**1) 클로드 코드에 그대로 복붙**
> 너는 카페 창업 컨설턴트야. 내가 열고 싶은 카페 컨셉을 **한 번에 하나씩** 질문해서 구체화해줘. 순서는 ① 타겟 손님 → ② 위치·상권 → ③ 시그니처 메뉴 → ④ 분위기·인테리어 → ⑤ 가격대 → ⑥ 차별점 → ⑦ 카페 이름·슬로건. 내가 막히면 보기를 2~3개 제안해줘. 하나씩만 물어봐.
>
> 다 끝나면 아래 형식으로 `my_cafe.md`를 만들어줘: 카페 이름 / 한 줄 컨셉 / 타겟 손님 / 위치·상권 / 시그니처 메뉴 / 분위기·인테리어 / 가격대 / 차별점 / 슬로건

**2) 솔직하게 답한다** — 정답 없음. "20대 여성 / 혼자 작업 / 동네"처럼 한 단어만 던져도 AI가 살을 붙인다.

**3) `my_cafe.md`가 생기면 열어본다.**

## ✅ 기대 결과 (하버 카페 예시)
```markdown
# 내 카페: 하버 카페
## 한 줄 컨셉
작업과 수다 사이, 골목 끝 아늑한 동네 카페
## 타겟 손님
20~30대 여성. 혼자 노트북 작업하거나, 친구와 사진 찍으러 오는 사람
## 위치·상권
주택가 골목 안, 대로변보다 조용. 근처 소형 오피스·대학
## 시그니처 메뉴
제주 말차로 만든 말차라떼, 당일 구운 수제 치즈케이크
## 분위기·인테리어
원목·따뜻한 조명·식물. 오래 머물고 싶은 느낌
## 가격대
아메리카노 4,500 / 시그니처 5,500 — 동네 평균보다 약간 위
## 차별점
옆 카페는 '사진 맛집', 우린 '머물러 작업하고 싶은 곳' + 사장님 친절
## 슬로건
"잠시 쉬어가는 항구, 하버 카페"
```

## 산출물

- 여유 되면: 메뉴판·로고 아이디어 이미지, 노션 공유
