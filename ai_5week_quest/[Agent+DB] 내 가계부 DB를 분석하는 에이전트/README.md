# 📜 [Agent+DB] 내 가계부 DB를 분석하는 에이전트

> 🎯 가계부 앱의 Supabase DB에 에이전트를 연결 → **말로 물어보는 소비 분석가**
> 구분: 🚩퀘스트 · 제출 기한: 토요일 23:59 PM

## ⚠️ 전제 조건
**[Server+DB] 가계부 앱** 퀘스트를 먼저 완료하고, Supabase에 지출 데이터가 **10건 이상** 쌓여 있어야 함. (데이터가 많을수록 분석이 풍부)

## 미션
### Part 1: 에이전트에 내 가계부 DB 연결
가계부 앱에서 쓴 같은 Supabase DB에 에이전트가 접속하도록 구성.

### Part 2: 말로 물어보기
- **기본 조회**: "이번 달 얼마 썼어?", "식비 가장 많이 쓴 날?", "교통비 월평균?"
- **패턴 분석**: "주중 vs 주말 비교", "요일별 지출 1위", "카테고리별 비율"
- **절약 조언**: "줄일 수 있는 것 추천", "50만원 예산 중 남은 예산?", "이 속도면 연말까지 얼마?"

## 핵심 구조
```
[가계부 앱으로 데이터 쌓기] → [에이전트가 Supabase DB 접속] → [질문] → DB 조회 + AI 분석 → [맞춤 답변]
```
- 앱 = 데이터를 *쌓는* 도구 / 에이전트 = *활용*하는 도구 / DB = 둘의 **공유 자산**

## 제출물
- GitHub 저장소 링크 (코드 포함)
- 에이전트 대화 스크린샷 (조회·분석·조언 각 최소 1장)
- 가계부 앱 스크린샷 (데이터가 쌓인 화면)

## 포인트 기준
| 항목 | 포인트 | 기준 |
|---|---|---|
| 기본 완료 | 10pt | 조회/분석/조언 스크린샷 필수 |
| 에이전트 활용 | 5pt | 2회 이상 대화하며 개선 |
| 창의성 | 5pt | 월간 리포트·카드값 알림·소비 등급 등 |
| 공유 보너스 | 5pt | 단톡방 공유 + 리액션 |

→ 기본 10 / 기본+활용·창의 15~20 / 올클리어 **25pt**

## 팁
- 가계부 앱과 **똑같은 Supabase 프로젝트·테이블**에 연결
- Supabase MCP를 쓰면 에이전트가 DB에 직접 접속 가능
- 질문은 구체적으로: "식비 얼마야?" < "이번 달 식비 얼마야? 지난달이랑 비교해줘"

## ✅ 제출 결과물 (완료)
- **배포 URL**: https://household-ledger-analyst.vercel.app
- **실행 화면**: `실행화면_스크린샷.png` (조회·분석·조언 질문 답변 포함)
- **핵심**: 1번 가계부와 **같은 Supabase DB / 같은 `household_ledger` 테이블**을 읽는 **읽기 전용 분석 레이어** (INSERT/UPDATE/DELETE 없음)
- **API**: `GET /api/stats`(합계·카테고리·요일별·일별·1위), `POST /api/ask`(자연어 질문 → 실제 집계 기반 답변)
- **데모 답변 예시**
  - 조회: "총 수입 3,350,000원, 총 지출 1,304,300원, 잔액 2,045,700원 (거래 18건)"
  - 조언: "지출 1위 '주거'(65.2%)와 2위 '식비'(8.6%)부터 점검 — 둘이 전체의 73.8%"
  - 분석: "주중 1,099,500원 vs 주말 204,800원"
- **창의성(5pt)**: 도넛·요일별 막대 차트 시각화 + 자연어 질문 챗(조회·분석·조언)
- **대화내용**: `[Agent+DB] 내 가계부 DB를 분석하는 에이전트 대화내용.txt` · `대화내용_스크린샷.png`
- 빌드: single-server-specialist(server.js) + single-react-dev(index.html) 에이전트로 작성
