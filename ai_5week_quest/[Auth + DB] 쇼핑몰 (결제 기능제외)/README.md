## ⚠️ 전제 조건
수업 튜토리얼 **Sign In & Sign Up & Profile**, **Todo App (+ Login & DB)** 완료 · Supabase 프로젝트 준비

## 미션
### Part 1: 상품 목록
DB에 상품 데이터를 넣고 목록 표시 (상품명·가격·이미지·설명). **로그인 없이도** 조회 가능.

### Part 2: 회원가입 & 로그인
장바구니 사용 시 로그인 필요하도록.

### Part 3: 장바구니
- **담기**: 목록에서 "장바구니 담기"
- **조회**: 내 장바구니 목록
- **수량 변경**: +/- 버튼
- **삭제**: 상품 제거
- **합계**: 총 금액 자동 계산

### Part 4: 배포
Vercel 배포 후 URL 제출.

**주제 예시**: 의류 · 문구/굿즈 · 디저트/베이커리 · 식물 가게 · 중고 전자기기

## 핵심 구조
```
[상품 목록 (DB)] → [장바구니 담기 (로그인 필수)] → [내 장바구니 관리] → [합계 계산]
```
**DB 테이블 (참고)**
```
products: id, name, price, image_url, description   (공개)
cart:     id, user_id, product_id, quantity         (본인만)
```
