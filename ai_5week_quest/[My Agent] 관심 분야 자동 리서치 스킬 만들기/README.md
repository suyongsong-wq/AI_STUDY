# 📜 [My Agent] 관심 분야 자동 리서치 스킬 만들기

> 🎯 반복하는 **웹 리서치 → md 정리 → 노션 공유**를 재사용 가능한 **스킬(SKILL.md)**로 박제
> 💡 핵심: 에이전트는 **한 번**, 스킬은 **매번**
> 구분: 🚩퀘스트 · 제출 기한: 토요일 23:59 PM

## 왜 '에이전트'가 아니라 '스킬'인가 (이번 주 핵심)
- 한 번 시키고 마는 건 **프롬프트**. 매주 반복되고 정리 방식(포맷)이 정해져 있으면 → **스킬**로 박제.
- 스킬 = `SKILL.md` 한 장에 **"언제 쓰는지 + 어떻게 하는지"**를 적어두는 것. AI가 그 절차를 **내 방식 그대로** 매번 재현.

## ⚠️ 전제 조건
Claude Code에 **브라우저 MCP(크롬/Playwright)** 연결. (Notion MCP도 연결하면 보너스)

## 미션
### Part 1 — 반복할 리서치 주제 정하기
"매주 이거 돌리면 되겠다" 싶은 주제 1개.
**예시**: 채용공고(원티드/사람인) · 동네 맛집 리뷰 · 부동산 매물 · IT 뉴스 요약 · 당근 가격 비교 · (창업 중이면) 경쟁 카페·신메뉴 트렌드

### Part 2 — 손으로 한 번 시켜보기 (워크플로 확정)
> 브라우저 MCP로 [내 주제] 관련 사이트 3곳 이상을 탐색해 핵심 정보를 모으고, `research.md`로 정리한 뒤 노션에 올려줘.

### Part 3 — 그 절차를 **스킬로 박제** (← 핵심)
> 방금 한 리서치 작업을 재사용 가능한 스킬로 만들어줘. `.claude/skills/research/SKILL.md`에 저장하고, `description`에는 **언제 쓰는지**를 적어줘. 본문 절차: ① 주제·키워드 묻기 → ② 브라우저 MCP로 사이트 3곳+ 탐색 → ③ 아래 포맷 md로 정리 → ④ 노션 공유. md 포맷은 (제목 / 수집일 / 출처별 핵심 / 한 줄 요약 / 다음 액션).

```markdown
---
name: research
description: 관심 주제를 받아 웹사이트 3곳 이상을 자동 탐색해 정보를 모으고, 정해진 포맷의 md로 정리한 뒤 노션에 공유한다. "관심분야 리서치", "리서치 돌려줘" 요청 시 사용.
---

# 관심분야 자동 리서치
1. 사용자에게 주제와 키워드를 묻는다.
2. 브라우저 MCP로 관련 사이트를 3곳 이상 연다.
3. 아래 포맷으로 `research-{날짜}.md`를 만든다.
   - 제목 / 수집일 / 출처별 핵심(사이트마다 3줄) / 한 줄 요약 / 다음 액션
4. Notion MCP가 있으면 노션 페이지로 공유한다.
```

### Part 4 — 스킬 재호출로 검증
**새 대화**를 열고 `관심분야 리서치 해줘` 한마디만. 같은 절차·포맷으로 나오면 성공. (키워드 바꿔 2번째도)

## 핵심 구조
```
[한 번 손으로] 주제 → 브라우저 MCP 탐색 → md 정리 → 노션 공유
                              │
                              ▼
[SKILL.md로 박제] → 다음부턴 "리서치 돌려줘" 한마디로 매번 재현
```

## 제출물
- 선택 주제와 탐색한 웹사이트 목록
- 에이전트가 자동 탐색하는 과정 스크린샷 (최소 3장)
- 만든 `SKILL.md` 파일 (또는 `.claude/skills/` 구조 스크린샷)
- 스킬 재호출 결과 2개 (같은 포맷으로 나오는지)
- (보너스) 노션 자동 업로드 결과 스크린샷

## 포인트 기준
| 항목 | 포인트 | 기준 |
|---|---|---|
| 기본 완료 | 10pt | 웹사이트 3곳+ 탐색 & md 제출 |
| 스킬 박제 | 5pt | `SKILL.md` 재호출이 실제 동작 |
| 창의성 | 5pt | 자기 주제 & 실용적 md 포맷 |
| 공유 보너스 | 5pt | 단톡방 공유 + 리액션 |

→ 기본 10 / 기본+박제·창의 15~20 / 올클리어(재호출까지 동작) **25pt**

## 팁
- "매주 돌릴" 주제일수록 스킬 가치가 큼
- *손으로 한 번 → 박제 → 고쳐쓰기* 순서로 (처음부터 완벽한 SKILL.md 노리지 말 것)
- 사이트 로딩이 느리면 에이전트에게 잠깐 기다리라고 지시
