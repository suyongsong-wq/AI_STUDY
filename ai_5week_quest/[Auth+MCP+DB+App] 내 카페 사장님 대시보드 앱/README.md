# 🅿️ [Auth+MCP+DB+App] 내 카페 사장님 대시보드 앱 (보스 퀘스트)

> 🎯 5주차에 배운 **Auth + MCP + DB + AI**를 하나의 앱에 종합. 로그인하면 카페 데이터가 한 화면에 모이고 AI가 브리핑해주는 **카페 사장님 대시보드**.
> ⚠️ **도전 퀘스트** — 다른 5주차 퀘스트를 먼저 완수한 수강생에게 추천. 위젯 **2~3개만 동작해도 인정!**
> 구분: 🚩퀘스트 · 제출 기한: 토요일 23:59 PM

## ⚠️ 전제 조건
내 카페(`my_cafe.md`)와 운영 데이터가 있으면 그대로 활용. 모든 기능을 완벽히 구현하지 않아도 됨.

## 미션
### Part 1: 로그인/회원가입 (Auth)
사장님만 대시보드에 접근하도록.

### Part 2: 데이터 소스 연결 (2개 이상)
- **Notion MCP**: 카페 할일/발주 메모 연동
- **DB (Supabase)**: 매출·메뉴 판매·재고 등
- **외부 API**: 날씨(손님 수 예측)·뉴스 등

### Part 3: AI 브리핑 생성
AI가 연결된 데이터를 종합해 **"오늘의 카페 브리핑"** 생성.

### Part 4: 대시보드 UI & 배포
하나의 웹앱에 표시 + Vercel 배포.

**대시보드 구성 예시**
```
┌─────────────────────────────────────────┐
│  좋은 아침, 하버 카페 사장님!   [로그아웃]  │
├──────────────┬──────────────────────────┤
│  오늘 할일     │  AI 브리핑                │
│  (Notion 연동) │  "어제 매출 38만원(+12%), │
│  □ 우유 발주   │   말차라떼 판매 1위. 오늘  │
│  □ 알바 면접   │   비 예보→디저트 할인 추천"│
│  ☑ 원두 입고   │                          │
├──────────────┼──────────────────────────┤
│  이번 주 매출   │  인기 메뉴 TOP3          │
│  (DB 연동)     │  1. 말차라떼 42잔         │
│  월:32만 화:28만│  2. 치즈케이크 31개      │
└──────────────┴──────────────────────────┘
```

## 핵심 구조
```
[로그인] → [Auth 확인] → [Notion MCP + 카페 DB + 날씨 API] → [AI가 데이터 종합] → [대시보드 표시]
```
