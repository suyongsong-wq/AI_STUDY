# 🅿️ 손님 리뷰·경쟁사 분석 → 엑셀/PPT 보고서 (20점)

> 🏪 **시나리오** — 하버 카페 사장님은 매일 결정을 내린다. *손님이 뭘 불평하지?*(리뷰), *옆 카페는?*(경쟁사). 에이전트가 모은 리서치를 **회의에 바로 들고 갈 엑셀/PPT 보고서**로 만든다.
> 🧩 5주차 '카페 창업' — 시장 조사 → 의사결정 편 (홍보·운영과 한 세트)
> 🔧 준비: `document-skills` 스킬 · 구분: 🚩퀘스트

5주차 실무 에이전트 산출물 **하나**를 현업에 바로 내는 **엑셀 또는 PPT 보고서**로 완성한다.

## 필수 제출물
1. 원천 데이터 / 리서치 결과 (`.md` 또는 `.csv`)
2. 변환된 **`.xlsx`**(수식·차트·서식) 또는 **`.pptx`**(표지·분석·추천·다음액션)
3. 생성 과정 + **결과 파일 열어본 실행 스크린샷**
4. (가점) Notion / 메일로 공유

## 루브릭 (20점)
| 항목 | 배점 | 기준 |
|---|---|---|
| 기능 | 10 | 실제 수식/차트/슬라이드가 **데이터 기반**(박제 X) |
| 실행화면 스샷 | 4 | 파일 열린 화면 |
| 완성도(UX) | 4 | 현업에 바로 낼 수준 |
| 창의 | 2 | 템플릿·디자인·자동화 |

### 경로 B — 경쟁사 분석 → PPT 보고서
**1) 아래를 `competitors.md`로 저장**
```markdown
# 하버 카페 주변 경쟁 카페 분석
## 시장 개요
- 반경 500m 내 카페 4곳, 직장인·대학생 상권. 평균 아메리카노 4,500원.
## 경쟁사 비교
| 카페 | 아메리카노 | 시그니처 | 인스타 팔로워 | 강점 | 약점 |
| --- | --- | --- | --- | --- | --- |
| A 빈브라더스 | 5,000 | 핸드드립 | 8,200 | 원두 퀄리티 | 가격 높음·좌석 적음 |
| B 카페모노 | 4,000 | 대용량 라떼 | 3,100 | 가성비 | 디저트 약함 |
| C 스윗아워 | 4,800 | 수제 디저트 | 12,500 | 디저트·인스타 강함 | 커피맛 평범 |
| 하버 카페(우리) | 4,500 | 말차라떼 | 2,400 | 균형·친절 | 인지도 낮음·웨이팅 |
## 분석
- 인스타 인지도에서 C(스윗아워)에 크게 밀림 (12.5K vs 2.4K)
- 디저트 강자 C, 가성비 B 사이에서 '균형+친절'이 차별점이나 아직 약함
- 웨이팅이 공통 약점이자 우리 리뷰 불만 1위
## 차별화 포인트
- 말차라떼 시그니처 + 디저트 세트로 C와 정면승부
- 인플루언서 협업으로 인지도 격차 축소
## 추천 액션
1. 디저트 세트 출시 (객단가↑, C 견제)
2. 인플루언서 3~5명 협업 (인지도↑)
3. 피크타임 대기 동선 개선 (공통 약점 해소)
```
**2) 요청 (복붙)**
> `competitors.md`로 **경쟁사 분석 PPT**를 만들어줘. 표지 / 시장 개요 / 경쟁사 비교표 / 우리 차별화 / 추천 액션. 깔끔한 톤으로.

✅ 기대: 표지 + 비교표·팔로워 차트 + 차별화·추천. 추천에 '인플루언서 협업'이 들어가 홍보 편과 이어짐

> 💡 두 경로 모두 같은 카페 이야기. **둘 다** 해보면 리뷰·경쟁 데이터가 사장님 의사결정 보고서로 바뀌는 흐름을 끝까지 경험. `my_cafe.md` 기준으로 바꾸면 만점에 더 가까움.

## ✅ 제출 결과물 (완료)

- **파일 열어본 화면**: `하버스카페_VoC분석.xlsx.png`, `하버스카페_경쟁사분석.pptx.png` (Quick Look 미리보기)
- **결론**: 긍정 '맛·작업환경', 부정 1위 '대기시간' → 웨이팅 개선 우선 / 인지도 약점 → 인플루언서 협업(9번과 연결)
- 생성: Python `openpyxl`(엑셀·차트) + `python-pptx`(슬라이드·표). 데이터는 my_cafe 기준 하버스카페 리뷰·경쟁사.
