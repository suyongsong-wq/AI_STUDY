# 📜 [Auth] 커뮤니티 앱

> 🎯 로그인한 사용자만 글 쓰고, 자기 글만 수정/삭제하는 커뮤니티 앱
> 구분: 🚩퀘스트 · 제출 기한: 토요일 23:59 PM

## ⚠️ 전제 조건
수업 튜토리얼 **Sign In & Sign Up & Profile**, **Todo App (+ Login & DB)** 완료 · Supabase 프로젝트 준비

## 미션
### Part 1: 회원가입 & 로그인
커뮤니티에 가입하고 로그인하는 화면.

### Part 2: 게시글 CRUD
- **작성**: 로그인한 사람만 (제목 + 내용)
- **조회**: 로그인한 누구나 (작성자 이름 표시)
- **수정/삭제**: 자기가 쓴 글만

### Part 3: 게시글 목록
최신순 목록 — 제목·작성자·작성 시간 표시, 클릭 시 상세 보기.

### Part 4: 배포 & 공유
Vercel 배포 후 가족/친구/수강생에게 공유해 실제 가입·글쓰기 유도.

**커뮤니티 주제 예시**: 우리반 자유게시판 · 오늘 뭐 먹었어요 · 반려동물 자랑 · 영화/드라마 리뷰 · 자유

## 핵심 구조
```
[회원가입/로그인] → [게시글 목록 (전체 공개)] → [글쓰기 (로그인 필수)] → [수정/삭제 (본인만)]
```
- Auth = "누가 썼는지" 기록 / DB = 게시글+작성자 저장 / 앱 = 권한 차등 부여

## 제출물
- 배포된 앱 URL (Vercel)
- GitHub 저장소 링크
- 스크린샷 (회원가입 → 로그인 → 글쓰기 → 목록)

## 포인트 기준
| 항목 | 포인트 | 기준 |
|---|---|---|
| 기본 완료 | 10pt | 로그인 + 게시글 CRUD + 배포 URL |
| 에이전트 활용 | 5pt | 2회 이상 대화하며 개선 |
| 창의성 | 5pt | 자기만의 주제 & 쓸 만한 UI |
| 다른 사람 인증 | 5pt | 본인 외 1명+ 실제 가입·작성 (스샷 필수) |

→ 기본 10 / 기본+활용·창의 15~20 / 올클리어 **25pt**

## 팁
- Todo App 구조 그대로 활용 (Todo→게시글, 제목/내용/작성자 추가)
- 4주차 익명 게시판이 있으면 Auth만 추가하는 전략도 OK
- RLS(Row Level Security)로 "자기 글만 수정/삭제" 깔끔하게
- 다른 사람 인증 보너스를 위해 일찍 배포·공유
