[최종 결과물]
- my-voice.md                         : 내 말투 규칙 정리 (실습 A)
- .claude/skills/my-reply/SKILL.md    : 내 말투 답장 초안 스킬 (실습 C)
- cafe-context.md                     : 카페 상황별 응대 규칙 + 가게정보 (카페 연결)
- 본 대화내용.txt / 스크린샷

------------------------------------------------------------------
0. 말투 추출 준비
------------------------------------------------------------------
나: 내 말투로 답장 초안 쓰기(메일·슬랙·카톡). 내 메시지 20개 정도 추려줘.

AI: 직접 친 메시지가 담긴 파일이 필요 → 2~4주차 퀘스트 "대화내용.txt"들에서
    내가 실제로 친 메시지(사용자:/나: 줄) 50여 개를 grep으로 추출.
    그중 말투가 잘 드러나는 20개 선별 + 핵심 말투 패턴 정리.

    [뽑아낸 내 말투 핵심]
    1) 짧고 직설적인 명령형 (~줘/~해/~라/~봐), 군더더기 없음
    2) 반말 + 캐주얼, 막히면 "야 안뜬다" "키 죽은 거임?"
    3) 결정이 빠름 ("2번만" "가장 쉬운 걸로" "3번 빼고")
    4) 목적 지향, 길어지면 → 와 약어로 압축
    5) "이해되게 설명해" 자주 요구
    6) 불만은 짧게, 대안은 바로

------------------------------------------------------------------
1. 실습 A — 내 말투 뽑아내서 my-voice.md 로 저장
------------------------------------------------------------------
나: 실습 A처럼 지금 뽑은 대화로 퀘스트 시작. (스크린샷 첨부)

AI: 추출 표본이 전부 'AI에게 친 명령형 메시지'라는 점을 명시.
    → 핵심 말투는 실제 데이터로 확정, 채널 규칙(카톡/슬랙/메일)은 톤 기반 투영.
    my-voice.md 생성:
    - 어디서나(공통) / 격식 수준 / 문장 길이·형태 / 이모지 습관
    - 피해야 할 말투 (과한 사과·번역투·느낌표 남발·요청 여러 개 묶기)
    - 채널별 규칙: 카톡(그대로) / 슬랙(반말+정돈) / 메일(직설+존댓말 전환)

------------------------------------------------------------------
2. 실습 B — 써보기 (적용 테스트)
------------------------------------------------------------------
나: my-voice.md 말투로 이 메일에 답장 초안 써줘:
    "안녕하세요, 협업 제안 관련해서 단가표 받아볼 수 있을까요?"

AI: 메일 규칙(존댓말 전환, 용건→정보→요청) 적용한 초안 작성.
    > 안녕하세요, 송수용입니다.
    > 협업 제안 감사합니다. 단가표 첨부해 드립니다.
    > 작업 범위에 따라 단가가 달라져서, 아래만 알려주시면 맞춰 정리해 드리겠습니다.
    > - 협업 항목 / 분량
    > - 희망 일정
    > 확인 후 회신 부탁드립니다.

------------------------------------------------------------------
3. 실습 C — 스킬로 박제
------------------------------------------------------------------
나: 방금 정한 내 말투를 재사용 스킬로 만들어줘.
    .claude/skills/my-reply/SKILL.md 에 저장하고, description엔
    "받은 메일·슬랙·카톡 메시지에 내 말투로 답장 초안을 써준다"라고 언제 쓰는지 적어줘.
    본문엔 my-voice.md 톤을 따르되 채널(메일/슬랙/카톡)에 맞춰
    길이·격식·이모지를 조절하라고 적어줘.

AI: 기존 recipe 스킬 프론트매터 형식 확인 후 my-reply/SKILL.md 생성.
    - 0단계: my-voice.md 로드  → 1단계: 채널 판별(표)
    - 2단계: 답장 작성(용건 먼저, 어미만 채널에 맞게, 금지 말투 차단)
    - 3단계: 출력 형식(초안만 인용블록, 메일이면 제목, 조정 옵션, 빈칸 플레이스홀더)

나: 테스트 해봐.

AI: /my-reply 호출. [슬랙] "내일 회의 자료 오늘 안에 공유 가능?" 으로 테스트.
    > ㅇㅋ 오늘 안에 공유할게.
    > 초안은 (○시)까지 올리고, 최종본은 퇴근 전까지 정리해서 줄게.
    > 혹시 우선 봐야 할 부분 있으면 알려줘.
    → 슬랙 톤(반말+정돈), "ㅇㅋ/~할게" 상용표현 반영, 정상 동작 확인.

------------------------------------------------------------------
4. 카페 연결 (cafe-context.md)
------------------------------------------------------------------
나: 카페같은거랑 연결이 가능함? (손님 리뷰 답글, 인플루언서 DM→홍보, 거래처 메일)

AI: 가능. 말투(my-voice)는 그대로, 가게 정보·상황별 규칙을 담은
    cafe-context.md를 따로 만들어 스킬이 함께 읽게 하는 방식 추천.
    → 컨텍스트 파일 추가 방식 선택 / 3종 상황 전부 제작.

    cafe-context.md 생성:
    - 가게 기본정보 (샘플: 하버스카페·성수동·흑임자 라떼·@harbors.cafe)
    - 공통 원칙: 대외 응대라 반말 카톡 톤 금지(존댓말 기본), 복붙 느낌 금지
    - 상황1 리뷰: 별점 분기(호평=감사+추천 / 악평=사과 1줄+개선+재방문)
    - 상황2 DM: 친근+빠른 결정, 무료 협찬 덜컥 수락 금지 → 조건 역질문
    - 상황3 거래처 메일: 용건→정보(글머리표)→요청+서명
    SKILL.md에 "카페 상황이면 cafe-context.md도 함께 읽기" 규칙 추가.

나: 샘플 값으로 넣어. / 서로 실행해보고 테스트해줘.

AI: 카페 3종 동시 테스트 (★5 리뷰 / 무료협찬 DM / 원두 발주 메일).
    - 리뷰: "흑임자 라떼 인생라떼라니 기쁘네요! ... 바스크 치즈케이크도 추천드려요.
            또 뵙겠습니다 :) — 하버스카페 드림"
    - DM: "관심 감사해요! 협업 열려 있어요. 다만 방문 협찬은 건마다 조율 →
           일정·콘텐츠 형태(피드/릴스·게시 수) 먼저 알려주시면 안내드릴게요."
    - 거래처: 제목 "원두 추가 발주 요청 — 하버스카페" + 용건/수량/납기 글머리표.
    → 두 파일 로드·상황 판별·별점 분기·가게정보 주입·무료협찬 가드·빈칸 처리·
      금지 말투 차단 전 항목 정상 동작 확인.
