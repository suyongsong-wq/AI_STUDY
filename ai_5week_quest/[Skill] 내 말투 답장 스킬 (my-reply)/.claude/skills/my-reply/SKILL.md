# 내 말투 답장 초안 스킬 ✍️

받은 메시지에 **내 말투(my-voice)** 로 답장 초안을 써준다.
톤의 기준은 이 스킬 폴더의 `my-voice.md`. 항상 그 파일을 먼저 읽어 최신 규칙을 따른다.
(경로는 이 SKILL.md와 같은 디렉터리 = 스킬 base 디렉터리 기준.)

## 0단계 · my-voice.md 로드

- 이 스킬 폴더의 `my-voice.md`를 읽어 핵심 톤·피해야 할 말투·채널별 규칙을 파악한다.
- 파일이 없으면 사용자에게 알리고, 아래 핵심 톤 요약으로 대체한다:
  - 짧고 직설적인 명령형 / 1문장 1요청 / 군더더기·인사·쿠션어 없음
  - 빠른 결정, 목적 지향, `→`로 압축
  - 과한 사과·번역투·느낌표/이모지 남발 금지
- **카페 상황이면** 이 스킬 폴더의 `cafe-context.md`도 함께 읽는다. 단서: 손님 리뷰·별점,
  인플루언서/협찬 DM, 원두·납품·발주 거래처 메일, 또는 인자에 `[리뷰]/[DM]/[거래처]` 표기.
  - 이때 말투(my-voice)는 유지하되 cafe-context의 **상황별 규칙·격식·서명**을 우선 적용한다.
  - 리뷰 답글·DM·거래처 메일은 대외 공개/응대이므로 반말 카톡 톤 금지(존댓말 기본).

## 1단계 · 채널 판별

원문과 사용자 요청에서 채널을 정한다. 불명확하면 묻지 말고 단서로 추정한다.

| 채널 | 단서 | 격식 | 길이 | 이모지/느낌표 |
|------|------|------|------|--------------|
| 카톡 | 반말·짧은 문장·"ㅋㅋ/ㅇㅋ" | 반말 그대로 | 1~3줄 | 최소(리액션 정도) |
| 슬랙 | 업무 채널·멘션·스레드 | 반말 유지 + 정돈 | 2~5줄 | 리액션용 최소 |
| 메일 | "안녕하세요"·제목·존칭 | 존댓말 전환 | 인사+본론+요청 | 거의 없음 |

## 2단계 · 답장 초안 작성

공통 원칙(my-voice.md 따름):
- **용건 먼저.** 한 줄로 핵심 → 필요 정보 → 요청 순서.
- **직설은 살리되 채널 격식에 맞춰 어미만 조절**한다.
  - 카톡: "~줘 / ~해 / ~임?"  ·  슬랙: "~해줘 / 확인 부탁"  ·  메일: "~해주세요 / 부탁드립니다 / 가능할까요?"
- 과한 사과·장황한 서두·번역투·느낌표 남발 금지.
- 한 메시지에 요청 여러 개 욱여넣지 않기. 정보 나열은 글머리표로.

메일일 때 권장 구조:
```
안녕하세요, 송수용입니다.
(한 줄 용건 / 감사)
(필요 정보 — 글머리표)
(확인/회신 부탁으로 마무리)
```

## 3단계 · 출력 형식

- 답장 **초안만** 인용블록으로 깔끔히 출력한다.
- 채널이 메일이면 제목 한 줄도 함께 제안한다.
- 초안 아래에 **짧은 조정 옵션** 1~3개 제시(더 짧게 / 더 정중하게 / 빈칸 채우기 등).
- 빈칸이 필요한 부분(일정·금액 등)은 `(○○)` 플레이스홀더로 남기고 무엇을 채워야 하는지 알린다.

## 예시

입력(메일): "안녕하세요, 협업 제안 관련해서 단가표 받아볼 수 있을까요?"

출력:
> 안녕하세요, 송수용입니다.
> 협업 제안 감사합니다. 단가표 첨부해 드립니다.
> 작업 범위에 따라 단가가 달라져서, 아래만 알려주시면 맞춰 다시 정리해 드리겠습니다.
> - 협업 항목 / 분량
> - 희망 일정
> 확인 후 회신 부탁드립니다.
