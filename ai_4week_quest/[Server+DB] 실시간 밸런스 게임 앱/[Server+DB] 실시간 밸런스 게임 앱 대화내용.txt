실시간 밸런스 게임 앱 — 제작 대화 내용
======================================================================

[과제 목표]
Server + DB(Supabase)를 조합해 실시간 밸런스 게임 투표 앱 제작
1. 밸런스 게임 질문 등록 (A vs B)
2. 둘 중 하나에 투표 → 실시간으로 퍼센티지 변화
3. 투표 결과 + 총 참여자 수 표시
4. 모든 데이터를 Supabase DB에 저장
핵심 구조:
  [질문 등록(A vs B)] → [투표 선택] → [Server] → DB 저장
  → 실시간 투표율 계산 → 퍼센티지 바 업데이트

1) 두 에이전트 분업 (서버 / 프론트)
----------------------------------------------------------------------
나: single-react-dev 와 single-server-specialist 둘이 작업해.
    질문도 너네가 임의로 등록해줘. 검증도 해주고.

AI: 형제 앱([Server+DB] 익명 고민·칭찬 게시판)과 동일한 위치(ai_4week_quest)
   ·네이밍·구조·주석 스타일을 따르기로 하고, 먼저 API 계약(contract)을 확정해
   두 에이전트에 동일하게 전달했습니다. (서로 안 맞는 것을 막기 위함)
   - 테이블: questions(option_a, option_b) + votes(question_id, choice)
   - GET  /api/questions                  (질문 + A/B 집계, 최신순)
   - POST /api/questions {optionA,optionB}
   - POST /api/questions/:id/vote {choice} (핵심: votes INSERT → 집계 반환)
   - DELETE /api/questions/:id
   - 질문 객체: {id,optionA,optionB,votesA,votesB,total,percentA,percentB,createdAt}
   - 투표율: total=A+B, percentA=round(A/total*100), percentB=100-percentA

   두 에이전트(single-server-specialist / single-react-dev)를 동시에 실행했으나
   둘 다 일시적 서버 과부하(API 529)로 작업 전에 종료됐습니다. 그래서 확정된
   계약·형제 앱 골격을 그대로 받아 메인(저)이 직접 server.js / index.html을
   작성하고 끝까지 검증했습니다.

   [생성 파일]
   - server.js     : Express + pg(Pool) + dotenv, 테이블 2개 자동 생성 + 시드
   - index.html    : CDN React + Tailwind 단일 파일 밸런스 게임
   - package.json  : express / pg / dotenv
   - .env.example  : DATABASE_URL, PORT (비밀번호 자리표시자)
   - vercel.json   : 배포 설정
   - .gitignore    : node_modules / .env / .vercel

2) 시드 질문 임의 등록 (돈·직장 테마)
----------------------------------------------------------------------
나: 질문도 너네가 임의로 등록해줘.

AI: questions 테이블이 비어 있을 때만(initDB에서 COUNT 확인) 4주차 주제(돈/직장)에
   맞는 밸런스 게임 질문 6개를 자동 INSERT 하도록 했습니다.
   ① 월급 500 + 주7일 출근      vs 월급 300 + 주4일 출근
   ② 월세 50만원 깨끗한 신축    vs 전세 대출 끼고 낡은 내 집
   ③ 매일 카페에서 커피 사먹기  vs 회사 탕비실 믹스커피
   ④ 로또 1등 당첨금 한 번에    vs 매달 평생 200만원씩
   ⑤ 점심값 아껴서 저축         vs 맛있는 점심 먹고 행복
   ⑥ 연봉 높은데 야근 많은 회사 vs 연봉 적당하고 칼퇴 회사
