# 냉장고 재료 기반 레시피 스킬 — 푸짐한 한상 모드 🍲

냉장고에 있는 재료로 **여럿이 나눠 먹을 푸짐한 한 상**을 차려 준다.

## 실행 순서 (반드시 이 순서대로)

1. **재료 읽기**: `ingredients/` 폴더의 **모든 `.json` 파일을 먼저 읽는다.**
   - 각 파일은 `{ "name", "quantity", "category" }` 형태의 재료 1개다.
   - 파일이 없으면 "냉장고가 비어 있어요. ingredients/ 폴더에 재료 JSON을 추가하세요."라고 안내하고 종료한다.
2. **재료 파악**: 읽은 재료 목록을 표로 정리해 보여준다.
3. **레시피 생성**: 아래 **한상 조건**에 맞춰 **메인 1 + 사이드 1~2**로 구성한다.
4. **저장**: 생성한 한상 구성을 `recipes/` 폴더에 마크다운 파일로 저장한다.
   - 파일명: `recipes/레시피-<대표요리이름>.md`
5. 저장한 파일 경로를 사용자에게 알려준다.

## 한상 조건 (레시피 생성 기준)

- **2~3인분** 기준으로 분량 계산
- **메인 요리 1개 + 사이드/국물 1~2개**로 상을 구성
- 같은 재료를 메인과 사이드에 나눠 쓰는 **재료 효율** 고려
- 손님 접대용으로 **플레이팅·곁들임** 한 줄 제안
- 상차림 순서(먼저 끓일 것 → 마지막에 볶을 것)를 정리

## 저장할 마크다운 형식

```markdown
# 🍲 <대표 요리 이름> 한상

> 푸짐한 한상 모드 · 2~3인분

## 사용한 냉장고 재료
- 재료 (분량)

## 🍛 메인 — <요리 이름>
1. ...

## 🥢 사이드 — <요리 이름>
1. ...

## 상차림 팁
- ...
```
