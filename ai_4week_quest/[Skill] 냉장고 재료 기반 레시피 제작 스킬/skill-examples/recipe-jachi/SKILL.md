# 냉장고 재료 기반 레시피 스킬 — 자취생 모드 🍳

냉장고에 있는 재료로 **자취생도 바로 따라 할 수 있는** 한 끼 레시피를 만들어 준다.

## 실행 순서 (반드시 이 순서대로)

1. **재료 읽기**: `ingredients/` 폴더의 **모든 `.json` 파일을 먼저 읽는다.**
   - 각 파일은 `{ "name", "quantity", "category" }` 형태의 재료 1개다.
   - 파일이 없으면 "냉장고가 비어 있어요. ingredients/ 폴더에 재료 JSON을 추가하세요."라고 안내하고 종료한다.
2. **재료 파악**: 읽은 재료 목록을 표로 정리해 보여준다.
3. **레시피 생성**: 아래 **자취생 조건**에 맞는 레시피 1~2개를 만든다.
4. **저장**: 생성한 레시피를 `recipes/` 폴더에 마크다운 파일로 저장한다.
   - 파일명: `recipes/레시피-<요리이름>.md`
5. 저장한 파일 경로를 사용자에게 알려준다.

## 자취생 조건 (레시피 생성 기준)

- **1인분** 기준으로 분량 계산
- **조리 15분 이내**, 불 하나 / 전자레인지 정도로 끝나는 난이도
- 추가로 필요한 재료는 **소금·간장·기름 등 기본 양념 위주**로만 가정
- 설거지가 적게 나오는 **원팬·원볼** 우선
- 냉장고 재료만으로 부족하면 "이것만 더 사면 완성!" 섹션에 1~2개 추천

## 저장할 마크다운 형식

```markdown
# 🍳 <요리 이름>

> 자취생 모드 · 1인분 · 약 ○○분

## 사용한 냉장고 재료
- 재료 (분량)

## 추가로 필요한 것 (있으면)
- ...

## 조리 순서
1. ...
2. ...

## 자취 꿀팁
- ...
```
