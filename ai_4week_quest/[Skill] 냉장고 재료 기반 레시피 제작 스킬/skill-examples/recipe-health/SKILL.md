# 냉장고 재료 기반 레시피 스킬 — 건강식 모드 🥗

냉장고에 있는 재료로 **영양 균형 잡힌 건강한 한 끼**를 설계해 준다.

## 실행 순서 (반드시 이 순서대로)

1. **재료 읽기**: `ingredients/` 폴더의 **모든 `.json` 파일을 먼저 읽는다.**
   - 각 파일은 `{ "name", "quantity", "category" }` 형태의 재료 1개다.
   - 파일이 없으면 "냉장고가 비어 있어요. ingredients/ 폴더에 재료 JSON을 추가하세요."라고 안내하고 종료한다.
2. **재료 파악**: 읽은 재료를 표로 정리하고, 각 재료를 **탄수화물 / 단백질 / 채소** 군으로 분류한다.
3. **레시피 생성**: 아래 **건강식 조건**에 맞는 레시피 1~2개를 만든다.
4. **저장**: 생성한 레시피를 `recipes/` 폴더에 마크다운 파일로 저장한다.
   - 파일명: `recipes/레시피-<요리이름>.md`
5. 저장한 파일 경로를 사용자에게 알려준다.

## 건강식 조건 (레시피 생성 기준)

- **1인분** 기준, 칼로리는 대략 **500kcal 이내**를 목표로
- 기름·설탕·나트륨을 줄인 **저염·저당 조리법** 우선 (찌기/굽기/삶기)
- **단백질 + 채소**가 한 끼에 함께 들어가도록 구성
- 각 레시피에 **예상 칼로리**와 **간단 영양 코멘트**를 포함
- 부족한 영양군이 있으면 "이걸 곁들이면 균형 완성" 추천

## 저장할 마크다운 형식

```markdown
# 🥗 <요리 이름>

> 건강식 모드 · 1인분 · 약 ○○kcal

## 사용한 냉장고 재료
| 재료 | 분량 | 영양군 |
|------|------|--------|
| ... | ... | 단백질/채소/탄수 |

## 조리 순서
1. ...
2. ...

## 영양 코멘트
- 예상 칼로리: ○○kcal
- ...
```
