[과제 목표]
Server + DB(Supabase)를 조합해 익명 연봉/지출 비교 앱 제작
1. 사용자가 익명으로 월급·월 지출·직군/연차 등을 입력
2. 제출하면 전체 평균·분포·내 위치(상위 몇 %)를 표시
3. 카테고리별 평균 지출(식비·주거·교통·구독료 등)도 비교
4. 모든 데이터를 Supabase DB에 익명으로 저장
핵심 구조:
  [익명 입력(월급·지출·직군)] → [Server] → DB 저장
  → 전체 평균/분포 계산 + 내 위치 산출 → 결과 응답
  · DB 역할 : 익명 데이터 저장소 + 통계 조회(AVG, COUNT, GROUP BY)
  · Server 역할 : 데이터 등록 API + 통계/비교 API 제공

1) 두 에이전트 분업 (서버 / 프론트)
----------------------------------------------------------------------
나: single-react-dev 와 single-server-specialist 둘이 제작해.

AI: 형제 앱([Server+DB] 익명 고민·칭찬 게시판)과 동일한 위치(ai_4week_quest)
   ·네이밍·구조·주석 스타일을 따르기로 하고, 먼저 API 계약(contract)을 확정해
   두 에이전트에 동일하게 전달했습니다. (서로 안 맞는 것을 막기 위함)
   - 테이블: salary_submissions
     (job_category, region, years, salary, exp_food/housing/transport/subscription/etc)
   - 모든 금액 단위는 "만원" 정수
   - POST /api/submissions {jobCategory,region,years,salary,expenses{...}}
       → INSERT 후 "내 위치"(salaryTopPercent/expenseTopPercent/salaryVsAvg/
         totalExpense) + 전체 stats 즉시 반환
   - GET  /api/stats
       → count, salary{avg,min,max,median,distribution[6구간]},
         expenses{카테고리별 평균,total}, byJobCategory[], byRegion[]
   - 상위 % 정의: 나보다 많이 버는(쓰는) 사람 비율, 작을수록 상위

   두 에이전트(single-server-specialist / single-react-dev)를 동시에 실행했으나
   둘 다 Write 권한 거부로 파일 생성 직전에 멈췄습니다. 그래서 확정된 계약·형제
   앱 골격을 그대로 받아 메인(저)이 직접 server.js / index.html을 작성하고
   끝까지 검증했습니다.

   [생성 파일]
   - server.js     : Express + pg(Pool) + dotenv, salary_submissions 자동 생성
   - index.html    : CDN React + Tailwind 단일 파일 (입력 폼 + 통계 대시보드)
   - package.json  : express / pg / dotenv
   - .env.example  : DATABASE_URL, PORT (비밀번호 자리표시자)
   - vercel.json   : 배포 설정
   - .gitignore    : node_modules / .env / .vercel

2) 통계 SQL 설계 (AVG · COUNT · PERCENTILE · GROUP BY)
----------------------------------------------------------------------
AI: DB의 진짜 힘("데이터가 모이면 의미가 생긴다")을 살려, 통계는 전부 SQL로
   계산하도록 했습니다.
   - 평균 월급 : AVG(salary), 중앙값 : PERCENTILE_CONT(0.5)
   - 분포      : CASE로 6개 구간(200만 미만 ~ 600만 이상) 버킷팅 후 GROUP BY
   - 직군별    : GROUP BY job_category (평균 월급 내림차순)
   - 카테고리별 평균 지출 : AVG(exp_food), AVG(exp_housing) ...
   - 내 위치   : COUNT(*) FILTER (WHERE salary > 내월급) / 전체 * 100
   데이터 0건일 때 0으로 나누는 일이 없도록 안전 분기도 넣었습니다.
