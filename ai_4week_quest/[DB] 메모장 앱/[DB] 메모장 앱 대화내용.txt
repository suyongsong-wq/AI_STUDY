AI: single-server-specialist 에이전트로 백엔드를 구성했습니다.
    - server.js : Express + pg(node-postgres)
    - Supabase pooler 연결이라 SSL 설정 필요
      (ssl: { rejectUnauthorized: false })
    - 서버 시작 시 memos 테이블 자동 생성
      (id, title, content, created_at, updated_at)
    - CRUD REST API
        GET    /api/memos       전체 목록(최신순)
        POST   /api/memos       생성
        PUT    /api/memos/:id   수정
        DELETE /api/memos/:id   삭제
    - 비밀번호는 코드에 하드코딩하지 않고 .env(DATABASE_URL)에서 읽음
    - .gitignore로 .env, node_modules 제외 (비밀번호 깃에 안 올라감)

나: (DB 비밀번호 전달)

AI: 비밀번호에 특수문자(* $ - .)가 있어 연결 문자열에서 URL 인코딩 처리.
      *  ->  %2A
      $  ->  %24
    .env의 DATABASE_URL에 안전하게 반영했습니다.
    ※ 비밀번호를 채팅에 평문 입력했으니, 제출 후 Supabase에서
       비밀번호 재설정(rotate) 권장.
