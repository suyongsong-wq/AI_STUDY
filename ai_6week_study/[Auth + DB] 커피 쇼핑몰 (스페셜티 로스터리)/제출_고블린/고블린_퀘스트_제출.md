## 🐹 G1. [Payment] 100원 결제 성공 (테스트 키) — 15pt (+5)

**핵심 플로우**: `결제 위젯 표시 → 결제 요청 → 승인 API 호출(서버) → DB 주문 저장` ✅ 전 구간 실동작

### 무엇을 했나
- 토스페이먼츠 **결제창(`payment()`) SDK v2** 연동 (`https://js.tosspayments.com/v2/standard`)
  - ⚠️ 발급된 키가 **API 개별 연동 키(`test_ck_`/`test_sk_`)** 뿐이라 `widgets()`는 "API 개별 연동 키는 지원하지 않습니다" 에러 → **의도적으로 `payment()` 결제창 방식** 채택 (전문 검증 에이전트가 "올바른 판단"으로 확인)
- 승인 API는 **반드시 서버에서** 호출 — `POST /api/payments/confirm`가 Secret Key(Basic 인증)로 토스 승인. **Secret Key는 프론트/깃에 노출 0** (`.env`·서버 env에만)
- 승인 성공 시에만 `coffee_orders` + `coffee_order_items` 저장 → 장바구니 자동 비움

### 실제 결제 성공 증빙
- **토스 매출전표** (`screenshots/01_토스결제완료_영수증.png`)
  - 결제금액 **69,000원** · 결제수단 **카카오페이-카드(현대)** · **승인번호 00168055** · 주문번호 `EMBER_20da157273404ddeb286` · 2026/07/07 21:48:04
- **DB 저장 확인** — `coffee_orders` 주문 `#A33CE925`, `total_price 69000`, `status paid`, `paid_at 21:48:04` (영수증과 일치)
- **테스트 결제**라 실제 청구 0원 (`test_` 키 + 토스 sandbox `payment-gateway-sandbox.tosspayments.com`)

### 보너스 (+5) — 주문 상세
- 마이페이지 주문 카드에서 **상품명 / 금액 / 주문번호(#앞8자리) / 결제상태**를 표시 (`screenshots/04_...`)

## 🐹 G2. 쇼핑몰: 마이페이지 — 10pt (+5)

### 무엇을 했나
- 헤더 **`마이페이지`** 버튼(로그인 시) → 전체화면 계정 페이지
  - **프로필**(이니셜 아바타·이메일·가입일·회원ID) · **요약 통계**(총 주문·총 구매금액·누적 원두) · **주문 내역** 섹션 (`screenshots/03_`, `04_`)
- **본인 주문만** — Supabase RLS `auth.uid() = user_id` (DB 차원 권한 제어, `coffee_orders`/`coffee_order_items`)
- **최신순** 정렬 (`paid_at DESC`)
- **주문번호** 8자리 표시 (`#A33CE925`)
- **빈 상태 화면** 구현 ("아직 주문 내역이 없어요")

### 보너스 (+5) — 주문 안 상품 상세
- 각 주문의 상품별 **수량 / 단가 / 합계** 표시 (`₩18,000 × 3 = ₩54,000`) — `order_items`에 상품명·단가 스냅샷 저장으로 상품 변경/삭제에도 내역 보존

## 🧩 참고 — 전문 에이전트 검증
`tosspayments-widget-integrator` 에이전트로 결제 연동 검증 수행:
- ✅ 키 분리·서버 승인 강제·`payment()` 채택·query(`?toss=success`) 파싱·플로우 완결성·재confirm 가드 = 견고
- ⚠️ 금액 서버 검증(price-tampering)·orderId DB 저장은 실서비스 전 보완 권장 (테스트/데모엔 무영향). Low 2건은 반영 완료.
