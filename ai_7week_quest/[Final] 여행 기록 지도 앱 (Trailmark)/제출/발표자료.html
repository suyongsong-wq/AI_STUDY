PROBLEM

여행의 기억은
24시간이면 사라진다

  • 인스타 스토리는 하루 뒤 사라지고, 사진첩은 뒤죽박죽
  • "내가 어디를 왜 좋아했는지"는 시간이 지나면 휘발
  • 가족·친구와 여행 기록을 한 곳에서 모아볼 방법이 없음

→ 여행을 사랑하지만 그 기록이 자꾸 사라져 아쉬운 나 자신을 위한 앱

SOLUTION

다녀온 나라를 지도에서 긁는다

  • 은박으로 덮인 세계 지도
  • 방문한 나라만 대륙별 컬러로 드러남
  • 긁는 순간 리빌 애니메이션
  • 도시엔 국기 핀 + 여행 다이어리

한 여행의 여러 도시를 그룹으로. 사이드바·경로 패널이 여행별 섹션으로 정리되고 색이 자동 배정.

✈️

여행 경로

방문일 순 경로 라인 + 순번 배지. 드래그로 순서 편집이 그룹 안에서 가능.

📸

지도 공유 카드

TECHNICAL CHALLENGE

제일 어려웠던 것: 태평양 중심 지도

  • 표준 세계지도는 경도 ±180°에서 끊겨, 한국 중심 뷰에선 아메리카 쪽 색칠·핀이 사라짐
  • 대서양(-30°)에서 지도를 자르고, 서쪽 조각(아메리카)을 +360° 이동 — 나라 조각 단위라 찢김 없음
  • 러시아·알래스카처럼 날짜변경선을 걸친 나라는 먼저 이어붙인 뒤 이동
  • 극지방을 감싸는 남극 폴리곤은 변환이 불가능 → 제외로 해결
  • 저장은 표준 좌표(-180~180)로 정규화 — DB는 깨끗하게 유지

→ 서울에서 LA로 가는 경로가 태평양을 건너는 자연스러운 선이 됐다

TECH STACK

빌드 도구 없는 단일 파일 앱

프론트

index.html 단 한 파일 — React 18(UMD) + Tailwind CDN + Leaflet 1.9. 지도 데이터는 world GeoJSON(무료·키 불필요).

백엔드

Supabase — Auth(이메일) · Postgres 테이블 6개 + RLS 정책 전수 검증 · Storage(사진) · Edge Function(평점 프록시).

지오코딩

OSM Nominatim 자연어 검색(한글 지원) + 도시/행정구역 우선 랭킹 + tm_cities 캐시로 반복 호출 제거.

배포

Vercel + 가비아 도메인 trailmark.co.kr (A/CNAME + SSL). OG 카드·파비콘까지 캔버스로 직접 생성.
