# 회고 — Trailmark v1

**잘 된 점.** "기능 10개 반쪽보다 1개 완성"이라는 이번 퀘스트의 원칙을 그대로 따랐다. 스크래치 맵이라는 코어 경험 하나를 정하고 — 은박을 긁는 리빌 애니메이션, 국경 모양 그대로의 hover, 대륙별 컬러까지 — 끝까지 다듬었다. 특히 한국 중심 뷰에서 아메리카 쪽 지도가 사라지는 문제를 태평양 중심 좌표계 변환(대서양에서 자르고 아메리카를 +360° 이동)으로 정면 돌파한 게 가장 뿌듯하다. trailmark.co.kr 도메인 배포 후 실제로 다른 수강생이 공유 초대를 보내와서, 함께 보기(내 나라/친구 나라/같이 간 나라 3색 뷰)가 실사용으로 검증된 것도 좋았다. 매 기능을 브라우저에서 실제 구동으로 확인하고 RLS를 SQL로 직접 검증하며 만든 덕에, 별도 리뷰에서 나온 결함 10건(XSS·사진 유실·고아 파일 등)도 배포 전에 잡을 수 있었다.

**아쉬운 점.** 구글 평점은 rating 필드가 가장 비싼 Enterprise SKU라는 걸 확인하고 Edge Function 프록시 + 캐시 구조까지만 만들고 키 연결을 보류했다. 도시 검색이 무료 Nominatim에 의존해 랜드마크 검색 품질이 들쭉날쭉한 것, 구글·카카오 로그인이 버튼만 준비된 것, 다이어리가 도시당 1개 대표 글 중심인 것은 v2 숙제로 남긴다.
