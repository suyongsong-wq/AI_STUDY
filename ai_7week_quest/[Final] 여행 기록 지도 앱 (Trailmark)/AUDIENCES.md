# AUDIENCES — 누구에게 어떻게 알릴 것인가? (Trailmark)

> 개인 프로젝트 기획서 3종 중 **Part 3**. MISSION(왜/무엇) · DEV(어떻게 만드는가)에 이어,
> **"누구에게 어떻게 도달할 것인가"** 를 정의한다.
> 제품 전제: Trailmark = 세계 지도 스크래치 맵 + 도시별 여행 다이어리 + **가족·친구 공유** ( https://trailmark.co.kr )
> ※ 페르소나는 스펙 지침대로 **가상이되 구체적**으로 작성. 실측 수치를 지어내 넣지 않는다.

## 1. 타겟 페르소나 3명

### 페르소나 A — "사라지는 게 아까운 사람"
- **이름 / 나이 / 직업**: 김서연 / 28 / IT 스타트업 마케터
- **여행 성향**: 1년에 2~3번 해외여행, 사진 수백 장씩 찍음
- **지금 겪는 문제**: 여행 순간을 **인스타 스토리로만 올리는데 24시간 뒤 사라짐.** 사진첩엔 수천 장이 쌓였지만 폴더가 뒤죽박죽이라 "그때 그 골목이 어디였지?"가 기억 안 남. *"내가 어디를 왜 좋아했는지"가 휘발되는 게 늘 아쉽다.*
- **Trailmark가 주는 것**: 다녀온 나라를 지도에서 긁고, 도시별 다이어리로 **영구 보관**.

### 페르소나 B — "둘이 함께 채우고 싶은 사람"
- **이름 / 나이 / 직업**: 이준호 / 33 / 3년 차 신혼, 제조업 엔지니어
- **여행 성향**: 아내와 국내·해외 여행. 커플 계정·공유 앨범을 이미 쓰는 타입
- **지금 겪는 문제**: 둘이 다닌 곳이 각자 폰에 흩어져 있음. **"우리가 함께 간 지도"** 를 한 장으로 보고 싶은데 마땅한 게 없음. 스크래치 맵(실물)은 붙여둘 벽도, 업데이트할 방법도 애매.
- **Trailmark가 주는 것**: 이메일 초대 → **부부가 같은 지도를 함께 채우는** 공유 모드.

### 페르소나 C — "가본 나라를 세고 싶은 사람"
- **이름 / 나이 / 직업**: 박지우 / 24 / 휴학 중 대학생, 배낭여행러
- **여행 성향**: 유럽·동남아 배낭여행, "가본 나라 N개국" 카운트에 로망. 스크래치 맵 실물 사려다 접음
- **지금 겪는 문제**: 여행 기록이 인스타·블로그·노션에 파편화. **"내 세계 지도 진행률"** 을 시각적으로 보고 싶은데 무료로 깔끔한 게 없음.
- **Trailmark가 주는 것**: 대륙별 진행률 % + 방문 국가/도시 통계 + 스크래치 맵 시각화.

> **공통 축**: 세 명 다 "여행 기억이 흩어져 휘발된다"는 MISSION의 문제를 각자 다른 각도(보관 / 함께 / 수집)로 겪는다.

## 3. 첫 10명 획득 전략 3가지 (행동 단위)

### 전략 1 — 공유 기능을 지렛대로 "지인 5명 직접 초대"
Trailmark의 핵심 차별점이 **가족·친구 공유**다. 즉 첫 사용자는 마케팅이 아니라 **제품 안에서** 나온다.
- **행동**: 내가 먼저 내 지도를 5개국 이상 채워두고 → 가족·친구·연인 **5명에게 앱 내 이메일 초대** 발송
- **멘트**: *"우리 같이 간 여행 지도로 채워보자"* (초대받은 사람이 회원가입 → +5명)

### 전략 2 — 인스타 릴스 1편 + 여행 해시태그
- **행동**: 실제로 **세계 지도를 긁어 채우는 화면 15초 릴스** 제작 → `#여행기록 #스크래치맵 #세계여행` 태그 + 프로필 링크에 `trailmark.co.kr`
- **행동**: 같은 영상을 **여행 오픈채팅방·지인 단톡방**에 "이런 거 만들었어" 링크로 공유
- **목표**: 릴스·단톡방에서 **호기심 클릭 → 가입 3~5명**

### 전략 3 — 여행 커뮤니티에 "만든 후기글" 1편
- **행동**: 네이버 여행 카페 / 에타 여행 게시판에 **"여행 다녀온 거 지도로 기록하는 웹앱 만들었어요 (무료)"** 후기글 작성 — 스크린샷 3장 + 링크
- **핵심**: "더 많은 기능"이 아니라 **"다른 각도"** 로 소구 (무료 · 한국어 · 가입 즉시 사용 · 가족과 함께)
- **목표**: 후기글 유입 **2~3명**

> **합산 목표: 5(초대) + 3~5(릴스) + 2~3(후기글) = 첫 10명 확보.**
> 세 전략 모두 **광고비 0원, 내가 지금 당장 실행 가능한 행동 단위**로만 구성 — MISSION의 "실제로 누가 써볼 수 있는 v1" 정의에 맞춘다.
