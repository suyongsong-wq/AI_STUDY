## G1. YouTube 썸네일 만들기 (1920×1080) — 15pt (+5)
> 🎯 내가 좋아하는 유튜버의 영상 썸네일을 1920×1080으로 만들어보세요!

**설명**
좋아하는 유튜버의 영상 한 편을 골라서, 그 영상에 어울리는 유튜브 썸네일을 직접 디자인해보세요.
- **1920×1080 사이즈 (16:9 비율)** 고정
- 영상 주제가 한 눈에 들어오는 굵직한 카피
- 시선을 끄는 강조색 + 인물/이미지 합성

**팁**
> 💡 실제 썸네일을 레퍼런스로 옆에 띄워두고 따라 만들어보세요. 비슷하게 만들수록 안목이 늘어요!
- 폰트는 두껍고 큰 사이즈로 (Pretendard Black, Black Han Sans 등)
- 핵심 키워드 1~2개에만 강조색 (빨강·노랑) 적용
- 인물 사진은 배경 제거 후 합성하면 임팩트 ↑
- 작아져도 읽히는지 **300×170 미리보기**로 꼭 확인

**보너스 (+5pt)**: 같은 영상에 대해 **A/B 두 가지 버전**을 만들고, 어떤 게 더 클릭하고 싶은지 비교
> ⚠️ 반드시 위 항목을 다 완료 & Commit 한 뒤 보너스 추가

## 1. [Final] 당근마켓 클론
> 🎯 당근마켓을 직접 만들어보면서, 부트캠프에서 배운 **Auth + DB + 이미지 업로드 + 채팅**을 한 번에 통합. 마지막 퀘스트, 끝까지 밀어붙입시다.

**전제 조건**
> ⚠️ **Auth + DB(Supabase) + Storage(이미지 업로드)**를 모두 사용해본 상태여야 합니다.
> 5~6주차 퀘스트(커뮤니티 앱 / 쇼핑몰)를 완료했다면 이 퀘스트의 **80%는 이미 익숙**합니다!

**미션**
- **Part 1 — 회원가입 & 로그인**
  - 이메일 가입 + **동네 설정** (직접 입력 또는 위치 인증)
- **Part 2 — 상품 등록**
  - 이미지(**최대 3장**) + 제목 + 가격 + 설명 + 카테고리
  - 본인만 수정/삭제 가능 (**RLS**)
- **Part 3 — 상품 목록 & 상세**
  - 최신순 목록 + 카테고리 필터 + 키워드 검색
  - 상세 페이지: 이미지 슬라이드, 정보, 작성자, **"관심" 버튼**
- **Part 4 — 채팅 (1:1 문의)**
  - 상품 상세에서 "채팅하기" → 판매자와 1:1 채팅
  - **Polling**으로 실시간 메시지 (주기적으로 DB 변화 체크)
- **Part 5 — 마이페이지**
  - 내가 등록한 상품 / 관심 상품 / 채팅 목록
- **Part 6 — 배포**
  - Vercel 배포 + 공유 가능한 URL

**핵심 구조**
```
[가입/로그인] → [상품 등록 (이미지+정보)] → [목록/검색] → [상세 → 채팅] → [마이페이지]

Auth: 누가 등록했는지 / 누가 채팅하는지
DB: 상품 + 사용자 + 채팅 메시지
Storage: 상품 이미지 업로드
Realtime: 실시간 채팅
```

> 💡 **깨달아야 할 핵심**: 당근마켓이 어렵게 느껴지지만, 사실은 (1) 글쓰기 + (2) 이미지 업로드 + (3) 1:1 채팅의 조합입니다. 그동안 만든 퀘스트들의 합성이라고 생각하세요.

**제출물**
- 배포된 앱 URL (Vercel)
- GitHub 저장소 링크
- **시연 영상** (가입 → 상품 등록 → 검색 → 채팅까지, **1분 이내**)
- **본인 외 1명 이상이 가입 & 채팅한 스크린샷**

**포인트**: 기본 10(가입+상품 등록+목록/상세+배포 URL) / **채팅 구현 5**(1:1 실시간 채팅 동작) / 에이전트 활용 5 / **다른 사람 인증 5**(본인 외 1명 이상 실제 가입 & 채팅, 스크린샷 필수) → **올클리어 25pt**

**팁**
> 💡 채팅은 가장 까다로우니 **순서를 마지막에** 두세요. Part 1~3만 잘 굴러가도 80% 완성입니다.

## 2. [Design] 카페 메뉴판 만들기
> 🎯 내가 카페 사장이라고 상상해보세요. 손님이 처음 봤을 때 "여기 들어가고 싶다" 싶은 **카페 메뉴판 한 장**을 디자인하세요.

**미션**
- **Part 1 — 카페 컨셉 잡기**
  - 카페 이름, 분위기(예: 미니멀 / 빈티지 / 코지), 타겟 손님을 **한 줄씩** 정리
  - 컨셉에 맞는 **컬러 팔레트(3색 이내)**와 **폰트(2개 이내)** 선정
- **Part 2 — 메뉴 구성**
  - **카테고리 3개 이상** (커피 / 논커피 / 디저트 등)
  - **메뉴 8개 이상**, 가격 포함
  - **시그니처 메뉴 1개** 선정
- **Part 3 — 메뉴판 디자인**
  - 사이즈: **A4 세로** 또는 **1080×1350**
  - 시그니처 메뉴는 사진·일러스트 + 강조색으로 시선을 잡기
